# Vanta Market — بوت متجر وتذاكر Discord

بوت Discord مستقل يعمل على Node.js 20 أو أحدث باستخدام discord.js v14 وSQLite عبر better-sqlite3. الواجهة والرسائل داخل Discord بالعربية. لا يحتوي المشروع على موقع أو لوحة تحكم أو خادم ويب.

## الوظائف

- الأمر `/store` ينشر قائمة المتجر مع شعار Vanta Market:
  - Minecraft Java + Bedrock — **$13**
  - خدمة رقمية مرخّصة — **$8**
- أمر الإدارة `/custom_button` ينشئ زر طلب باسم وسعر تختارهما؛ يظهر الاسم في اسم التذكرة.
- الضغط على زر الطلب يفتح تذكرة تأكيد خاصة. يكتب العميل **تأكيد** أو **إلغاء**؛ التأكيد يرسل الطلب إلى روم الطلبات لموافقة الإدارة.
- عند الموافقة، تُحذف تذكرة التأكيد وتفتح تذكرة شراء ونقاش جديدة، وتُنبه العميل وعضو الإشعارات.
- يتضمن الطلب اختيار تفضيل الدفع «كريبتو» أو «الاتفاق مع الموظف». هذا تفضيل فقط؛ لا توجد عناوين محافظ أو متابعة للتحويلات.
- أزرار **إنهاء العملية** و**حذف التذكرة** متاحة للإدارة فقط. الإنهاء يبقي التذكرة للموظفين، والحذف يزيل القناة.

## المتطلبات

- Node.js **20+**
- حساب بوت في Discord Developer Portal
- سيرفر Discord، ورتبة للموظفين، وقناة نصية للطلبات، وفئة للقنوات الخاصة
- تخزين قرص دائم لاستمرار قاعدة SQLite. استخدم نسخة احتياطية دورية للملف وقاعدة WAL.

## الإعداد

1. أنشئ تطبيقًا وبوتًا من [Discord Developer Portal](https://discord.com/developers/applications)، ثم انسخ رمز البوت سرًا. لا تشاركه ولا تضفه إلى Git.
2. أنشئ رتبة الموظفين وقناة الطلبات وفئة التذاكر في السيرفر. من إعدادات Discord فعّل **Developer Mode**، ثم انسخ معرّفات التطبيق والسيرفر والرتبة والقناة والفئة.
3. انسخ `.env.example` إلى `.env` واملأ القيم:

   | المتغير | القيمة |
   | --- | --- |
   | `DISCORD_TOKEN` | رمز البوت السري من Developer Portal |
   | `CLIENT_ID` | معرّف التطبيق |
   | `GUILD_ID` | معرّف السيرفر الذي سيعمل فيه البوت |
   | `STAFF_ROLE_ID` | معرّف رتبة الإدارة المسموح لها بالموافقة وإنهاء أو حذف التذاكر |
   | `ORDERS_CHANNEL_ID` | معرّف القناة النصية التي تستقبل الطلبات |
   | `TICKET_CATEGORY_ID` | معرّف فئة قنوات التذاكر |
   | `ORDER_NOTIFY_USER_ID` | معرّف عضو السيرفر الذي يُمنشن عند كل طلب وتذكرة شراء |
   | `DATABASE_PATH` | اختياري؛ مسار ملف SQLite، والافتراضي `./data/vanta-market.sqlite` |

4. فعّل **Message Content Intent** في إعدادات البوت؛ يحتاجه البوت للتعرّف على كلمتي **تأكيد** و**إلغاء** في تذكرة التأكيد.
5. ادعُ البوت إلى السيرفر بنطاقي OAuth2 `bot` و`applications.commands`. امنحه على الأقل:
   - View Channels
   - Send Messages
   - Read Message History
   - Embed Links
   - Attach Files
   - Manage Channels

   تحقق من إعدادات صلاحيات القنوات والفئة حتى يستطيع البوت إنشاء تذاكر خاصة وتعديل أذونات العميل عند الإغلاق. يجب أن يكون قادرًا على رؤية قناة الطلبات وفئة التذاكر.

## التثبيت والتشغيل

من داخل مجلد `bots/vanta-market-bot`:

```bash
npm install
npm start
```

يسجل البوت الأمرين `/store` و`/custom_button` تلقائيًا كأوامر خاصة بالسيرفر المحدد في `GUILD_ID` عند بدء التشغيل. لا تحتاج إلى سكربت أوامر منفصل. لاستخدام `/custom_button` أدخل اسم الزر والسعر؛ ينشر البوت زر الطلب في القناة الحالية. يعرض البوت خطأ واضحًا ويتوقف إذا كانت الإعدادات ناقصة أو كانت المعرّفات غير صحيحة.

للتأكد من صياغة ملف JavaScript:

```bash
npm run check
```

وتشغيل اختبارات قاعدة البيانات والأزرار:

```bash
npm test
```

## التشغيل على استضافة Node.js

ارفع مجلد `vanta-market-bot` إلى استضافة تدعم Node.js 20+، واضبط مجلد التشغيل عليه، ثم نفّذ `npm install` واجعل أمر التشغيل `npm start`. أضف متغيرات البيئة من لوحة الاستضافة بدل رفع `.env` إلى Git، ووجّه `DATABASE_PATH` إلى قرص دائم. لا تشغّل أكثر من نسخة للبوت على ملف SQLite نفسه؛ استخدم نسخة تشغيل واحدة لكل قاعدة بيانات.

إذا لم يكن القرص دائمًا، فستفقد قاعدة البيانات الطلبات والتذاكر عند إعادة إنشاء الخادم. احتفظ بنسخ احتياطية آمنة من ملفات قاعدة البيانات، وتأكد من حفظ ملفي `-wal` و`-shm` مع قاعدة البيانات عند نسخها أثناء التشغيل؛ والأفضل إيقاف البوت أو استخدام أداة نسخ SQLite متوافقة.

## حدود البوت والخصوصية

- لا يطلب البوت بيانات محافظ أو كلمات مرور أو عبارات استرداد، ولا يخزنها.
- التفاوض والتحويل المالي بين العميل والموظف خارج البوت؛ لا تُسجّل قاعدة البيانات حالة دفع أو إثبات تحويل.
- لا يسلّم البوت المنتجات تلقائيًا ولا يدّعي تأكيد الدفع.
- يحتوي `data/` و`.env` على بيانات محلية ويستثنيهما `.gitignore` من Git.
